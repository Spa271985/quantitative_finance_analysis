This project utilizes the mathematical ideas used in a small quantitative credit-risk project based
on public European Banking Authority (EBA) data, with Barclays Bank Ireland plc used as the
principal case study. It is written for readers and programmers who may be new to finance. Detailed mathematical concepts and project description with findings can be found inside Project 1 (P1) P1_Credit_Risk_Analysis_Barclays as credit_risk_analysis_EBAdata.pdf Each section first explains
the financial question in ordinary language and then introduces the corresponding calculation. The
analysis covers exposure composition, defaulted-exposure ratios, concentration measures, changes
through time, peer comparison, and a simple hypothetical stress-sensitivity exercise. These calculations with the codes are descriptive and educational: they do not reproduce an internal bank credit model, anexpected-credit-loss model, or an official regulatory stress test.Python-based credit-risk analysis of public European Banking Authority (EBA) data, covering exposure composition, default trends, HHI concentration, peer benchmarking and stress sensitivity.
